# 実装タスク一覧 v2(常駐 Bot 化 + スケジュール管理)

状態(2026-10-29 時点): フェーズ1(Bot 骨格、`/news`、`/status`、Docker 構成、死活監視 ping)、フェーズ2(予定・TODO・`/today` `/week`・朝のダイジェスト・`/settings`)、フェーズ3 の一部(繰り返し展開 V2-50/51)が実装済み。**次の未着手は V2-52(リマインド先行生成)以降**。V2-19(本番デプロイ)はユーザー作業で未確認。V2-21(単一インスタンスロック)は実装予定の新規タスク。

設計: `resident-bot.md` / `schedule.md` / `roadmap.md`。v1 のタスク(T01〜T25)は `tasks.md`。実装後の挙動は `README.md` と `docs/operations.md` とコードが正。

凡例: 担当 = developer(src/, .github/, Dockerfile 等)、tester(tests/)、docs(docs/, README.md)、reviewer(読み取り専用)、security(読み取り専用)、リード(判断・確認)。
1タスク=小さな成果単位。developer と tester のタスクは同じ番号帯で並行可。tester タスクは対応する実装タスク完了後に着手。
ユーザー判断が必要な項目は「🔶判断」と明示(下記フェーズ0)。

状態の意味: ✅ 完了 / ◐ 一部(残りあり) / 未着手 / ユーザー作業(リポジトリ外の操作) / 要確認
